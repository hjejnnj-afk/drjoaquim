# Landing Page - Dr. Joaquim Ortodontia

Landing page profissional para consultório de ortodontia.

## 🚀 Deploy no GitHub Pages

1. **Crie um repositório no GitHub**
   - Nome sugerido: `drjoaquim` ou `drjoaquim.github.io`

2. **Faça upload de todos os arquivos**
   - Arraste toda esta pasta para o repositório
   - Ou use Git:
     ```bash
     git init
     git add .
     git commit -m "Landing page Dr. Joaquim"
     git branch -M main
     git remote add origin https://github.com/SEU-USUARIO/SEU-REPO.git
     git push -u origin main
     ```

3. **Ative o GitHub Pages**
   - Vá em Settings → Pages
   - Source: `Deploy from a branch`
   - Branch: `main` / `root`
   - Clique em Save

4. **Acesse seu site**
   - URL: `https://SEU-USUARIO.github.io/SEU-REPO`
   - Ou configure um domínio personalizado
